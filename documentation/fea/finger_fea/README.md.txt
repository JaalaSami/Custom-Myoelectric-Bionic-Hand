 Finger Prototype V2 - FEA Static Structural Analysis

 Overview
Static structural simulation evaluated on the finger module to test structural integrity under load.

- **Component:** Finger prototype V2.
- **Material Assigned:** PETG (Polyethylene Terephthalate Glycol).
- **Fixity / Constraints:** Fixed support at the base of the finger.
- **Load Case:** Applied 20N static force at the tip of the finger.
